# store/

Everything to paste into App Store Connect and Google Play Console.

- `listing.md` – titles, descriptions, keywords, promo text, what's new, categories
- `ratings-and-privacy.md` – age rating / content rating answers, Apple privacy label, Google Data safety
- `release-checklist.md` – pre-submission checklist
- `screenshots/` – generated by `npm run screenshots` (gitignored). Needs Playwright: `npm i -D @playwright/test && npx playwright install chromium`. Options: `--url <served app>`, `--only iphone-6.7,ipad-12.9`, `--out <dir>`.

Items marked **PLACEHOLDER** must be replaced by the owner before submission. Limits quoted (30-char title, etc.) are the stores' documented limits as of writing; re-check in the consoles.
